# 💻 Laptop Price Prediction Web App

This project is a machine learning-based web application that predicts laptop prices based on various features like brand, processor, RAM, storage, ratings, and discount.

## 🚀 Features
- Predicts laptop price using ML model
- Interactive UI using Streamlit
- Real-time price prediction
- Visual output (price graph)
- AI-based recommendations

## 🧠 Machine Learning
- Models used:
  - Gradient Boosting Regressor
  - K-Nearest Neighbors (KNN)
- Feature Engineering:
  - OneHotEncoding (categorical data)
  - StandardScaler (numerical data)
- Feature Selection:
  - SelectKBest
  - Mutual Information
- Model Tuning:
  - GridSearchCV
- Evaluation:
  - R² Score

## 📊 Data Analysis
- Data Cleaning
- Outlier Handling (IQR method)
- Exploratory Data Analysis (EDA)
- Correlation Analysis (Heatmap)
- Data Visualization (Matplotlib, Seaborn)

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Streamlit
